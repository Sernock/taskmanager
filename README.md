# TaskManager

**TaskManager** — простой REST API для управления задачами, написанный на Go с использованием фреймворка [Gin](https://github.com/gin-gonic/gin) JWT-аутентификации и интерграцией WebSockets для отправки сообщений в живом времени.

---

## Описание

Этот проект позволяет создавать, читать, обновлять и удалять задачи (CRUD) с защитой маршрутов через JWT токены. Идеально подходит для обучения или как стартовая база для более сложных приложений.

---

## Возможности

- Регистрация и логин пользователей с JWT аутентификацией
- Создание, получение, обновление и удаление задач
- Авторизация защищенных маршрутов через JWT Middleware
- Хранение данных в SQLite (или любой другой поддержуемой базе данных)

---

## Технологии

- Go 1.20+
- Gin — веб-фреймворк
- JWT ([github.com/golang-jwt/jwt/v5](https://github.com/golang-jwt/jwt))
- SQLite (или другая СУБД)
- godotenv для работы с переменными окружения

## Установка и запуск

1. Клонируйте репозиторий:

-  git clone https://github.com/yourusername/taskmanager.git
-  cd taskmanager

2. Создайте файл .env в корне проекта и добавьте в него:

- JWT_SECRET=your_secret_key

3. Установите зависимости:

- go mod tidy

4. Запустите программу:

- go run main.go

5. Api будет доступен по адресу:

- API будет доступен по адресу: http://localhost:8080

## Использование API

1. Регистрация:

POST /register
Content-Type: application/json

{
  "username": "user1",
  "password": "password123"
}

2. Логин:

POST /login
Content-Type: application/json

{
  "username": "user1",
  "password": "password123"
}

Ответ содержит токен:

Формат типа:

{
  "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..."
}

3. Работа с задачами(требует авторизацию):

<small>Добавьте в заголовок запроса:<small>

- Authorization: Bearer <ваш_jwt_токен>

Получить задачи:

Get /tasks

Создать задачу:

POST /tasks
Content-Type: application/json

{
  "title": "Новая задача",
  "description": "Описание задачи",
  "completed": false
}


Обновить задачу:

PUT /tasks/:id
Content-Type: application/json

{
  "title": "Обновленная задача",
  "description": "Новое описание",
  "completed": true
}

Удалить задачу:

DELETE /tasks/:id

## Поддержка WebSocket

1. Добавлен WebSocket хаб для рассылки сообщений клиентам
- Создан глобальный канал broadcast для отправки сообщений всем подключенным клиентам.

- Создан map clients для хранения активных WebSocket соединений.

- Реализована горутина StartWebSocketHub, которая слушает канал broadcast и рассылает сообщения всем клиентам.

2. WebSocket обработчик /ws
- Используется gorilla/websocket для апгрейда HTTP соединения до WebSocket.

- При подключении клиент добавляется в clients.

- Сервер слушает входящие сообщения от клиента в цикле.

- При отключении клиента — соединение закрывается и клиент удаляется из списка.

3. Интеграция WebSocket с CRUD операциями задач
- После создания, обновления или удаления задачи формируется JSON-сообщение с информацией о действии (create, update, delete).

- Это сообщение отправляется в канал broadcast, что приводит к рассылке всем подключенным WebSocket клиентам.

4. Логирование WebSocket событий (рекомендуется для отладки)
Добавлены логи подключения, получения сообщений и отключения клиентов.

- Это позволяет отслеживать активность WebSocket соединений.

5. Как проверить работу WebSocket:

- Запустить сервер.

- Подключиться к ws://localhost:8080/ws через WebSocket клиент (например, расширение браузера или специализированные инструменты).

- Выполнить операции над задачами через REST API (/tasks).

- В клиенте WebSocket должны приходить уведомления о создании, обновлении и удалении задач.
